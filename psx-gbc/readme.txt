VERSION 0.2.2 ('Cohesion')

As I've mentioned in the forums, even number releases will be marked more 'stable' than odd releases. 
So, keeping that in mind, I've fixed some things that has reduced the amount of crashing. 

Changelog:
	Fixed OAM RAM Allocation
	Fixed CP OPCode bug
	Fixed BIT Opcode bug
	Fixed RL Opcode bug
	Added Unalloc routines
	Added Screen Blanking after Menu
	Removed Unused Variables



VERSION 0.2.1 ('Reloaded')


Thanks for trying out this version.

Its been a very long time since we've done anything, And there's still a bit to go. 
A lot of roms will crash, unfortunately. Try and stick with 32k Roms.

Check on the website, and Forums often!


Controls:
	To get back into menu from emulation: 
		
		press L1 + R1 + L2 + R2 + Select + Start.


Burning Notes:
	Make sure that you have these files in the main directory:
	
	SYSTEM.CNF
	MAIN.EXE
	AGBEBANK.BIN
